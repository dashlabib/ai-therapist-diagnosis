A single-line diagnosis from your AI therapist: acute second-opinion syndrome — three chatbots consulted, one horoscope obeyed. The program writes the diagnosis to `/output/entry.txt`: one line, 124 characters, inside the 200-character gate, in a calm clinical voice with the laugh landing at the end.

## Run it

```sh
python3 main.py
```
